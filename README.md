# swamp-namecheap

Source of the swamp extension [`@sntxrr/namecheap-dns`](extensions/models/README.md):
read and safely edit a Namecheap domain's DNS host records, with
read-merge-write, read-back verification and dry run by default.

```bash
cd extensions/models
deno test --allow-read --allow-write --allow-env .
```
